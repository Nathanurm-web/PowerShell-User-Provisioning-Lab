# PowerShell User Provisioning Lab

## Overview

This project demonstrates basic Windows system administration tasks using PowerShell.

Tasks completed:

- Created local user accounts
- Created local security groups
- Added users to groups
- Exported user information to CSV
- Verified account and group membership

## Technologies

- Windows 11
- PowerShell
- Local User and Group Management
